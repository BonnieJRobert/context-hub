# Contributing

Government employees, members of the public, and the private sector are
encouraged to contribute by forking the repository and submitting a pull
request. Pull requests are evaluated by the repository guardians and, if
deemed beneficial, will be merged.

All contributors retain the original copyright to their contributions. By
contributing to this project, you grant a worldwide, royalty-free, perpetual,
irrevocable, non-exclusive, transferable license to all users under the terms
of the project's license.

## Before you submit

- Follow the structure and conventions in [ARCHITECTURE.md](ARCHITECTURE.md).
- Run `npm run lint:md` and resolve reported Markdown issues.
- Keep `AGENTS.md`, `.github/copilot-instructions.md`, and `.cursorrules`
  consistent where their guidance overlaps.
- For a new Copilot skill, use `.github/skills/<skill-name>/SKILL.md` and
  include valid YAML front matter with a name and description.
- Commit no secrets, personal information, or third-party content that is not
  approved for public release.
